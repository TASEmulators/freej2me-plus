NOTE: FreeJ2ME-Plus Web is a proof of concept and should be used mostly as a preview. The native binary runs much faster, has higher compatibility and is more stable.

Supply your J2ME JAR or KJX binary file here.

Some JARs might need its descriptor to be loaded in order to parse the required properties for boot, this is especially true for DoJa. Supply it here if needed.

DoJa requires a scratchpad file to be loaded in conjunction to its JAR and JAM. It must be supplied here.

All that's left now is to configure the base settings for FreeJ2ME-Plus.
