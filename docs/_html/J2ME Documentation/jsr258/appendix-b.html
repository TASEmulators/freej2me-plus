Appendix B. Recommended security practices for Java ME configurations and profiles

This appendix contains the recommended security practices for JSR 258 implementations in Java ME configurations and profiles.

Mobile Information Device Profile (MIDP) 2.0 (JSR 118)

The security permissions protect modifications made to the device's themes. Listing themes and getting information about them is allowed for all applications.

According to the MIDP 2.0 Recommended Security Policy (see reference [MIDP]) and later, related specifications such as Java Technology for the Wireless Industry (JTWI, JSR 185) and Mobile Service Architecture for CLDC (MSA, JSR 248), the permissions must be placed in some function group. The name and semantics of the function group will be decided by future MSA work.

The following table defines the MIDP 2.0 permissions and the methods protected by them. Note that these permissions must be used with MIDP in both CLDC and CDC environments. Other profiles implemented on top of CDC must use the CDC permission classes defined below in the section pertaining to CDC.

Table B.1. MIDP 2.0 permissions and protected methods for Mobile User Interface Customization API
Permission name Methods protected by the permission
javax.microedition.theme.manage

ThemeManager#removeTheme(String)

ThemeManager#createTheme(String)

SkinManager#removeSkin(String)

SkinManager#createSkin(String)
javax.microedition.theme.modify

Theme#updateElement(String, String)

Theme#updateToolkitElement(String, String, String)

Skin#updateApplicationElement(String, String)

Theme#commit()

Connected Device Configuration (CDC)

For implementations of the Mobile User Interface Customization API on top of the Connected Device Configuration certain security sensitive methods must be protected by security permissions.

This section defines permission classes suitable for use in profiles implemented on top of the CDC. The table below lists these permission classes and the methods protected by them. All permission classes are named permissions and must be direct subclasses of java.security.BasicPermission.

Table B.2. CDC security permissions for the Mobile User Interface Customization API
Permission class name Methods protected by the permission class
javax.microedition.theme.ManagePermission

ThemeManager#removeTheme(String)

ThemeManager#createTheme(String)

SkinManager#removeSkin(String)

SkinManager#createSkin(String)
javax.microedition.theme.ModifyPermission

Theme#updateElement(String, String)

Theme#updateToolkitElement(String, String, String)

Skin#updateApplicationElement(String, String)

Theme#commit()

See stub implementations ManagePermission.java and ModifyPermission.java for the permission class signature definitions.
